Critical fires — fix these before anything else
P0 — DAY 1 All 260 properties are marked inactive
Every property in the database has status: "inactive". TCMs cannot see room availability. The inventory module returns nothing. This is the core product utility — matching leads to rooms — and it is completely dark.
⚡ Fix in 30 seconds: db.properties.updateMany({}, {$set:{status:"active"}}) — one database command. Then register the /api/inventory endpoint.
P0 — DAY 1 /api/dashboard returns 404 — home screen is blank
Every user opens the app to an empty screen. This single broken endpoint kills the daily habit loop. No compelling reason to open the CRM = 0 daily active usage. The psychological cue → routine → reward loop is broken at step one.
⚡ Register the route. Return: leads to call today, overdue follow-ups, TCM rank, zone pipeline summary. Build time: 1 day.
P0 — DAY 1 0% follow-up rate — 451 leads, zero nextFollowUpAt set
Not a single one of 451 leads has a follow-up scheduled. Leads enter the CRM and die there. This is the #1 revenue leak — estimated ₹1.57 crore/year in MRR abandoned.
⚡ On lead creation, auto-set nextFollowUpAt = now + 2 hours. Add a "Call Now" banner on any lead older than 2h with no activity. Backend change: 4 hours of dev work.
P0 — DAY 1 API URL publicly visible on login page
The backend server URL (opsserver.gharpayy.in) is displayed on the public login screen. This exposes your API to probing, enumeration attacks, and competitors.
⚡ Delete one line of HTML. Takes 5 minutes. Do it today.
P0 — WEEK 1 Budget field has 150+ text formats — filtering is broken
"8-12k", "8to12", "₹8,000–₹12,000 per month", "BASIC 7k-11k" are all the same budget range stored as different strings. Matching, filtering, and analytics on budget are completely unreliable.
⚡ Replace freetext with budgetTier enum: BASIC (7–11k) / MID (12–16k) / PRIME (17–26k) / PREMIUM (27k+). Run migration on all 451 leads. 1 day of work.
P0 — WEEK 1 64 of 95 TCM agents have zero leads — ghost army
67% of registered TCMs have never received a single lead. These accounts are either churned agents, test accounts, or misconfigured zones — and they still have access to all lead data.
⚡ Audit all 95 accounts. Deactivate test accounts (test_mwb, demotcm etc). Re-zone idle agents. Revoke data access for deactivated users immediately.
HIGH Quotation validity is 20 minutes — killing conversions
29 quotations sent → only 3 bookings = 10.3% quote-to-booking rate. A 20-minute window forces a snap decision. Leads need to check with family, verify commute, compare options.
⚡ Change default validity to 48 hours. Add a "hold this room" pre-booking deposit of ₹2,000. Track quote_viewed_at. Auto-trigger follow-up 1 hour before expiry. 4 hours of dev work.

The killer insightread this
Gharpayy does not have a technology problem. It has a behavior problem. The CRM is being used as a digital notepad — not a sales engine. The win condition for the next 18 months is not a new feature. It is making it harder to work outside the CRM than inside it. The moment a TCM logs a call, their manager sees it. The moment they don't log for 48h, they stop receiving leads. Commission is only paid on bookings in the CRM. The moat is not the code. The moat is the data — generated by 95 motivated telecallers who log every interaction, every day.
